# 🎙️ Dicta 2.0 

¡Llega **Dicta 2.0**! 🎉 Una reconstrucción total con novedades increíbles para automatizar tu flujo de dictado.

### ✨ Novedades
- ⌨️ **Escritura Directa (Auto-Pegar)**: Dicta escribirá automáticamente tus frases donde tengas el cursor (Word, web, Slack...).
- 📷 **Emparejamiento QR**: Abre los ajustes, escanea el código QR desde tu móvil y conéctate al instante.
- 🌍 **Multi-idioma**: Soporte para Español, Inglés, Francés y Alemán.
- 🕰️ **Historial**: Guarda automáticamente tus 10 últimas transcripciones. 
- 🎨 **Nuevo Diseño Premium**: Una interfaz "Glassmorphism" elegante, arrastrable y flotante en tu escritorio.

### 🛠️ Mejoras
- **Copias infalibles**: El autocopiado ahora usa la API nativa del sistema, funcionando perfectamente aunque Dicta esté en segundo plano.
- **Auto-limpieza inteligente**: Si usas Auto-pegar, la app se limpia sola tras cada frase.
- **Seguridad y SSL**: Generación rápida de HTTPS para acceso al micrófono sin problemas en iOS/Android.

📥 **Descarga `Dicta 2.0.0.exe` abajo y empieza a dictar. (¡No requiere instalación!)**
